# ReminderGray

一款四象限待办应用，根据重要性和紧急程度管理任务。当前为第四阶段桌面组件测试版 `1.3.0-beta1`。

## 当前功能

- 四象限分别对应：立即做、安排做、委托做、尽量不做。
- 使用重要、紧急两个开关添加待办，也可以把输入中的草稿直接拖入任意象限。
- 支持可选日期与时间；不选择时不会保存或显示空时间。
- 主界面每个象限最多显示 4 条，点击右上角总数可查看全部待办。
- 详情页支持新增、编辑、完成、删除、调整时间和调整优先级。
- 已有待办可在主界面拖动到其他象限。
- 数据保存在本机，升级时保留已有待办；可与同一同步服务上的网页版交换待办。
- 桌面组件展示四象限的待办数量和首条任务；点击输入入口可打开首页并自动聚焦输入框，点击象限可进入对应详情。

## 第二阶段视觉

- 用户提供的图片分别用于应用图标和主界面背景。
- 四象限使用高透明度、偏灰色调的红、青、蓝、灰有色玻璃效果。
- 象限只保留待办、总数和背景行动提示，减少无关内容。
- 行动提示使用霞鹜文楷 Lite；字体及 OFL 许可随应用一起打包。
- 应用配色、交互与组件风格在后续版本中保持一致。

## 构建与运行

1. 使用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 选择 Android 8.0（API 26）或更高版本的设备。
4. 运行 `app` 配置。

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 桌面组件

安装并至少打开一次应用后，在桌面长按进入组件列表，找到 `ReminderGray`，添加“ReminderGray · 四象限”组件。推荐使用 4 × 4 桌面空间；从旧版升级的较小组件可长按拖动边缘调大。

## 第三阶段：本机同步测试

电脑安装 Node.js 20 或更新版本后，在 `sync-server` 目录设置环境变量 `REMINDERGRAY_TOKEN`（至少 12 位、不与他人分享），运行 `npm start`。默认网页地址为 `http://127.0.0.1:8787`，只接受本机连接；网页首次使用时输入同一密钥。模拟器中的应用点击首页云朵按钮，填写 `http://10.0.2.2:8787` 和密钥，点击“保存并同步”。后续在 Android 端点击“立即同步”；网页版在打开、编辑和定时检查时同步。断线时两端先保留本地改动，重新连接后继续同步；冲突改动保留副本而非静默覆盖。

此本机地址只用于电脑与 Android Studio 模拟器测试。真机和平板跨网络使用需要自行部署受信任的 HTTPS 服务；不要把密钥或 `sync-server/data` 目录提交到 Git。
