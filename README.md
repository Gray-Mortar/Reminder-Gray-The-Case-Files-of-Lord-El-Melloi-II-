# 四象限待办

一个面向 Android 的本地四象限待办应用，依据重要性和紧急程度将任务分为：

- 立即做：紧急且重要
- 安排做：重要但不紧急
- 委托做：紧急但不重要
- 尽量不做：不紧急且不重要

## 当前功能

- 添加、完成、删除待办
- 通过菜单或长按拖动切换象限
- 本地持久化保存，无需账号或网络
- 2×1 桌面组件，一次点击打开快速输入弹窗
- 四个象限的行动建议以低对比度文字显示在矩阵背景中

## 构建与运行

1. 使用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 选择 Android 8.0（API 26）或更高版本的设备。
4. 运行 `app` 配置。

调试 APK 生成位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 桌面组件

安装并至少打开一次应用后，在桌面长按，进入组件列表，找到“四象限待办”，添加“快速添加待办”组件即可。

原始网页原型保留在 `eisenhower-matrix.html`。
